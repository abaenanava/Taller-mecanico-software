Regla de acceso

Sin sesión, la API responde 401 y Vue vuelve al login. Con sesión sin rol autorizado, responde 403 con “Acceso no autorizado”. La protección se aplica en el servidor, no sólo en el menú.

Contenedores Docker

frontend:5173 entrega Vue · backend:8000 entrega Django · db ejecuta MySQL y conserva los datos en un volumen.

Separación de responsabilidades

Vue no accede a MySQL. La vista llama la API, la API invoca la fachada, la fachada aplica reglas y el repositorio persiste el resultado.
