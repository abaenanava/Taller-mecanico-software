# Documentación del frontend de Motora

Versión: 1.0.0. Guía para el perfil frontend, bajo [orquestador](../orquestador/orquestador.md).

## Alcance

Documentar solo lo pedido o afectado por el cambio. Revisar archivos reales antes de describir tecnologías, rutas, estados o pruebas. No convertir esta guía en una afirmación de funcionalidad implementada. No crear PDF, diagramas o reportes adicionales salvo solicitud.

## Contenido requerido

- Pantallas y navegación, formularios, campos y estados carga/vacío/error/éxito.
- Consumo real de API, sesión/CSRF y permisos compartidos entre ADMIN y RECEPCION.
- Build y revisión visual; capturas solo cuando se hayan obtenido.
- Vincular REQ/AC y distinguir implementado, propuesto y no verificado.
- Incluir archivos fuente, comandos realmente ejecutados y limitaciones.

## Revisión

Usar ejemplos ficticios; no incluir contraseñas, tokens, datos personales ni contenido de .env. Mantener rutas relativas válidas. Si falta evidencia, marcar pendiente; no inventar resultados. Un reporte por sí solo no valida el contrato ni autoriza corregir código.
